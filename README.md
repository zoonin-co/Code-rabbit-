# Operation Meridian Map

An interactive, single-page story-world map made for a screenplay. It shows a **fictional** joint narcotics investigation, "Operation Meridian," set across Manhattan and Brooklyn.

> **Fiction disclaimer:** The geography is real, but the case, the people, the agencies' activity, and the watch zones are all invented. Any resemblance to real people or operations is coincidental.

## Features
- SVG map of Manhattan and Brooklyn, with nearby NJ, Queens and the Bronx for context
- 11 fictional watch zones colour-coded by priority
- Layer toggles for watch zones, patrol routes, and lead links
- Agency filter, a zone list, and a briefing panel for the selected zone
- "Who knows whom" relationship web of invented characters
- Light and dark themes (follows your system setting); layout stacks on phones

## How to open it
No build or install is needed. Download or clone the repo, then open `operation-meridian-map.html` in any modern browser (double-click it, or drag it into a browser window). An internet connection is only needed to load the Google Fonts; without one it falls back to system fonts.
